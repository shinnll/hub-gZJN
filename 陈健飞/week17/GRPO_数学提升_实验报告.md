# 基于 GRPO 的强化学习提升模型数学能力 · 实验报告

## 实验结果：前后对比

| 难度 | 训练集 | 基线 | GRPO 全量 | GRPO LoRA |
|------|--------|------|-----------|-----------|
| L1 个位加法 | — | 0.00 / 0.98 / 1.00 | 0.96 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 |

| L3 三位加减 | ✔ | 0.02 / 0.40 / 0.76 | 0.96 / 0.90 / 0.94 | 1.00 / 0.92 / 0.94 |
| L4 表内乘法 | — | 0.00 / 0.56 / 0.88 | 0.82 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 |

**核心结论**：训练集内（L2/L3/L5）正确率从 **0.45 → 0.92（全量）/ 0.95（LoRA）**；格式遵循率从接近 **0 → ~1.0**；未训练难度（L1/L4/L6）也从 0.54 → 0.75，说明 GRPO 具有一定**泛化**能力，不是死记硬背。

### 各难度正确率增益

- 训练集内难度提升最大（L5 两位×一位从 0.20 跳到 0.88，+0.68）；
- L6 两位×两位始终很低（0.08→0.24），印证「太难的题组优势恒为 0、学不动」。


### 训练动态曲线

- 正确奖励从约 **0.55** 爬升并在高位震荡，末步约 **0.84**；格式奖励从近 0 缓慢升到约 **0.18**（格式冷启动）；
- `frac_reward_zero_std`（组内全同、无梯度的「退化组」占比）长期在 **0.05–0.65**，说明大部分步仍有可学习信号；
- 策略熵从 **0.57** 衰减到约 **0.10**，模型逐渐变「确定」——这是 GRPO 的典型现象（LoRA 版熵崩溃更明显）。
