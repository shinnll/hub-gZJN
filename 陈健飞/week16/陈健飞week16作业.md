# 第16周作业：课上未覆盖的开源大模型结构调研

| 模型 | 发布方·时间 | 路线定位 |
|------|------------|----------|----------|
| **LLaMA-3** | Meta · 2024.04/07 | dense 基座（RMSNorm+RoPE+GQA+SwiGLU） |

## 1. LLaMA-3：现代开源模型的"母体"架构

**来源**：Grattafiori et al., *The Llama 3 Herd of Models*, arXiv:2407.21783 (2024)

### 1.1 概览
LLaMA-3 是 Meta 发布的 **稠密（dense）、自回归、decoder-only** Transformer 家族，分 8B / 70B / 405B 三档。
作者明确写道：架构相比 LLaMA-2 "**偏离很小**，性能提升主要来自数据质量、多样性与训练规模**"——这意味着 LLaMA-3 是"经典 Transformer 的集大成者"而非激进创新者。

### 1.2 关键结构参数（取官方 Table 3）

| 规格 | 8B | 70B | 405B |
|------|----|----|------|
| 层数 | 32 | 80 | 126 |
| 隐维度 d_model | 4,096 | 8,192 | 16,384 |
| FFN 维度 | 14,336 | 28,672 | 53,248 |
| 注意力头 | 32 | 64 | 128 |
| **KV 头（GQA）** | **8** | **8** | **8** |
| 激活函数 | SwiGLU | SwiGLU | SwiGLU |
| 词表 | 128,000 | 128,000 | 128,000 |
| 位置编码 | RoPE (θ=500,000) | 同左 | 同左 |
| 预训练上下文 | 8K | 8K | 8K（后扩到 128K） |

### 1.3 结构特点

- **注意力 —— GQA（压缩 KV，但仍是全量注意力）**：无论模型多大，KV 头固定为 8 个，query 头按规模扩展（8B 的 g=4、70B 的 g=8、405B 的 g=16）。相比原版 MHA 大幅压缩 KV cache，但**本质是"少存 KV 的全量注意力"，并未走向课上的 MLA（低秩 latent）或 DSA（稀疏选择）**。这是 2026 旗舰升级的第一站。
- **FFN —— 稠密 SwiGLU**：标准 SwiGLU 瓶颈，无任何稀疏/专家结构。FFN 维度约 3.5× 隐维度。
- **残差流 —— 标准加法残差 + Pre-Norm RMSNorm**：与 LLaMA-2 一致，没有 mHC / AttnRes 这类可学习混合。
- **位置编码 —— RoPE 高基频**：把 RoPE 基频从 LLaMA-2 的 10,000 提到 **500,000**，使 8K 训练内能稳定外推到 32K；405B 再通过 **6 阶段连续预训练**（每段 ~100B token）把上下文从 8K 渐进推到 128K。注意：这是"外推"思路，而课上 2026 旗舰已改为"原生 1M 预训练"。
- **稳定化 —— 仅 RMSNorm**：靠 RMSNorm（去均值、只缩放）替代 LayerNorm，没有 QK-Norm、有界激活、输出门等工具箱。
- **训推协同 —— 完全分离**：无 MTP、无 FP4/FP8 QAT，标准 BF16 + AdamW，长上下文靠"改 RoPE 基频"的后训练实现。
- **训练数据小技巧**：文档间注意力掩码（防止同序列内不同文档互相 attend），长序列续训时很关键；128K 词表（100K tiktoken + 28K 非英）提升压缩率（3.17→3.94 字符/token）。


## 2. Mixtral 8×7B：开源 MoE 的开山之作

**来源**：Jiang et al., *Mixtral of Experts*, arXiv:2401.04088 (2024)

### 2.1 概览
Mixtral 8×7B 是 Mistral AI 于 2023.12 发布的 **首个广泛可用的开源权重 MoE 模型**，也是首个证明"少量大专家优于大量小专家"的实用级开源实现。它直接构建在 Mistral 7B 骨架上，**只把 dense FFN 换成稀疏 MoE 层，注意力机制原封不动**。

### 2.2 关键结构参数（取官方论文 + HF config）

| 规格 | 值 |
|------|----|
| 层数 | 32 |
| 隐维度 | 4,096 |
| 注意力头 / KV 头 | 32 / **8（GQA, g=4）** |
| **专家数 / 激活数** | **8 / 2（top-2）** |
| 每专家 FFN 中间维度 | 14,336（与 LLaMA-2-7B 的 dense FFN 同形） |
| 总参数 / 每 token 激活 | **46.7B / 12.9B**（激活比 ~27.6%） |
| 词表 | 32,000（SentencePiece BPE） |
| 位置编码 | RoPE (θ=1,000,000) |
| 上下文 | 32,768（滑动窗口 4,096，理论跨度 128K） |
| 激活 | SwiGLU（SiLU） |

### 2.3 结构特点（对照五条轴线）

- **注意力 —— GQA + 滑动窗口（SWA）**：沿用 Mistral 7B 的滑动窗口注意力（每 token 只看前后 4,096 窗口，复杂度 O(n·w)）+ GQA（8 KV 头）。SWA 是"局部注意力"的最简实现，理论跨度靠窗口叠加可达 128K。
- **FFN —— 稀疏 MoE（本课重点对照对象）**：
  - **每个专家本身就是一个 SwiGLU FFN**，与 dense 版形状完全一致；"8×7B"是营销名（8×7B≈56B 是错的，真实总参 46.7B，因为 embedding/注意力/归一化是共享的）。
  - **路由方式**：路由器对 8 个专家计算 **softmax 概率分布，取 top-2**[^mixtral_route]。⚠️ **关键差异**：课上 DeepSeek-V3 改用 **sigmoid 门控**（各专家独立打分、更稳），Mixtral 仍是 softmax——这是 MoE 路由路线的一次重要分歧点，作业里可以重点写。
  - **设计哲学**：只把"知识存储"的 FFN 稀疏化，保留"工作记忆"的注意力全局——因为稀疏 FFN 不破坏 token 间依赖，稀疏注意力才会。
- **残差流 / 稳定化**：标准加法残差 + RMSNorm，无 mHC/AttnRes、无 QK-Norm/有界激活。
- **训练**：无 aux loss 讨论（Mixtral 论文主要关注负载均衡的实证），标准 BF16，无 MTP/量化感知训练。


## 3. Gemma-2：Google 的高效稳定化路线

**来源**：Gemma Team, *Gemma 2: Improving Open Language Models at a Practical Size*, arXiv:2408.00118 (2024)

### 3.1 概览
Gemma-2 是 Google DeepMind 基于 Gemini 同源技术发布的开放权重家族（2B / 9B / 27B）。它**不是靠堆参数，而是靠架构合成**——把滑动窗口、全局注意力、GQA、logit 软上限、双重归一化、知识蒸馏巧妙组合，使 27B 在同类中"以小博大"。

### 3.2 关键结构参数（取官方技术报告）

| 规格 | 2B | 9B | 27B |
|------|----|----|------|
| 层数 | 26 | 42 | 46 |
| 隐维度 | 2,304 | 3,584 | 4,608 |
| 头 / KV 头 | 8 / 4 | 16 / 8 | 32 / 16（均 **GQA, g=2**） |
| 头维度 | 256 | 256 | 128 |
| FFN 维度 | 18,432 | 28,672 | **73,728（16× 隐维）** |
| 词表 | 256,128 | 256,128 | 256,128 |
| 激活函数 | **GeGLU** | **GeGLU** | **GeGLU** |
| 上下文 | 8,192 | 8,192 | 8,192 |
| 训练 token | 2T | 8T | 13T |

### 3.3 结构特点（对照五条轴线）

- **注意力 —— 局部/全局窗口交替 + GQA**：**每层交替**使用局部滑动窗口（4,096）与全局注意力（8,192 全上下文）。相比 Mistral 的"每层都滑动窗口"，Gemma-2 的交替方案在消融中表现更好。KV 头固定为 query 头的一半（g=2）。
- **FFN —— 稠密 GeGLU（非 SwiGLU！）**：⚠️ **易错点**：Gemma-2 用的是 **GeGLU**（GELU 门控），不是 LLaMA/Mixtral 的 SwiGLU（SiLU 门控）。27B 的 FFN 中间维度高达 73,728（16× 隐维），比通常 4~8× 大得多，是"宽 MLP"策略。dense，无 MoE。
- **残差流 —— Pre-Norm + Post-Norm 双归一化**：在 Gemma-1 仅 Pre-Norm 基础上，Gemma-2 **对每个子层的输入和输出都做 RMSNorm**，显著提升训练稳定性，使 27B 能从头训练（不靠蒸馏）。
- **稳定化工具箱（本课稳定化轴线的最佳对照）**：
  1. **Logit 软上限**：在自注意力层和最终输出层对 logits 做 `logits ← soft_cap · tanh(logits / soft_cap)`（注意力 cap=50.0，输出 cap=30.0），平滑限制幅值、防激活 runaway——与课上 DS-V4 的"硬 clamp ±10"、Kimi 的"SiTU 软限幅"思想相通但实现不同。
  2. **Query/Key 归一化**：计算注意力分数前，把 Q/K 归一化到近似单位方差（乘 √head_dim）。这与课上 DS-V4/GLM-5.2 的 **QK-Norm** 思想一致，但 Gemma-2（2024.06）更早落地。
- **训推协同 —— 知识蒸馏（训练侧巧思）**：2B、9B 不是标准 next-token 预测，而是**最小化与学生分布和教师（27B）分布的 KL 散度**；27B 从头训练。这让 2B 在偏好榜上反超 Mixtral 8×7B（激活参数多 10 倍）。无 MTP、无 FP4/FP8 QAT。


## 4. 横向对比总表（五条演进轴线）


| 维度 | LLaMA-3 | Mixtral 8×7B | Gemma-2 | 课上 2026 旗舰演进方向 |
|------|---------|--------------|---------|------------------------|
| **注意力** | GQA + 全量（θ=50万） | GQA + 滑动窗口(4K) | 局部(4K)/全局(8K)交替 + GQA(g=2) | MLA / DSA 稀疏 / 线性(KDA) / 压缩(CSA) |
| **FFN** | dense SwiGLU | **MoE 8选2**（softmax 门控） | dense **GeGLU**（27B 16×宽） | 256~896 专家 / noaux 偏置 / LatentMoE |
| **残差流** | 标准加法 + Pre-Norm | 标准加法 + Pre-Norm | 加法 + **Pre/Post 双 RMSNorm** | mHC 四路 / AttnRes 跨块残差 |
| **稳定化** | RMSNorm | RMSNorm | RMSNorm + **logit 软上限 + Q/K 归一化** | QK-Norm / 有界激活 / 输出门 / sink |
| **位置编码** | RoPE θ=500K（外推到128K） | RoPE θ=1M（滑动窗口） | RoPE（窗口交替） | YaRN / partial RoPE / NoPE |
| **训推协同** | 分离（BF16, 后训扩上下文） | 分离（BF16） | 分离 + **小模型知识蒸馏** | MTP 投机 / FP4+FP8 QAT / Muon |
| **总参 / 激活** | 8B~405B（全激活） | 46.7B / **12.9B** | 2B~27B（全激活） | 671B~2.8T / 37B~104B 激活 |
| **激活比例** | 100% | ~27.6% | 100% | 3%~9% |
| **上下文** | 8K→128K（外推） | 32K（窗口，理论128K） | 8K | 原生 256K~1M |
| **许可** | Llama 3 社区许可 | Apache 2.0 | Gemma 许可（商用友好） | 各异 |

## 5. 小结：在演进地图上的坐标

```
注意力: 全量(GQA) ──→ MLA/DSA/线性/压缩          [LLaMA-3, Mixtral, Gemma-2 都还在全量/GQA/窗口阶段]
FFN:    dense ──────→ 极端稀疏 MoE                 [仅 Mixtral 迈出了 MoE 第一步，LLaMA-3/Gemma-2 仍 dense]
残差:   加法 ───────→ mHC/AttnRes                  [三者都是标准加法残差]
稳定化: RMSNorm ───→ QK-Norm/有界/软上限/门       [Gemma-2 最接近，已有软上限+Q/K归一化]
训推:   分离 ───────→ MTP/FP4/蒸馏                 [Gemma-2 的蒸馏是训练侧唯一"协同"尝试]
```

**核心结论**：
1. 这三个模型共同定义了 **2026 旗舰升级前的"架构基线"**——dense/GQA/标准残差/RMSNorm/分离训练。
2. **MoE 的真正开源普及从 Mixtral 开始**，但细粒度、noaux、LatentMoE 是课上旗舰的进化。
3. **稳定化工具箱并非 2026 凭空出现**：Gemma-2 的 logit 软上限、Q/K 归一化，是 DS-V4/Kimi 有界激活、QK-Norm 的早期先声。
